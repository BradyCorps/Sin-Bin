# SINBIN UI Skin Pack v0.1

This pack is the first implementation proof for the live-match visual system. Its scope is deliberately limited to the **selected Violetta bench card**.

## Contents

- Two seamless material textures
- Neutral and selected nine-slice bench frames
- Reusable Energy pip SVG
- Existing Violetta transparent placeholder PNG
- Approved live-match rendering for temporary comparison
- Asset manifest, provenance record, and Codex integration brief
- Contact sheet and assembled preview

## Installation

Copy the contents of this pack's `public/` directory into the repository's `public/` directory. Copy `docs/ui/` into the repository's corresponding documentation directory.

Give Codex `docs/ui/CODEX_INTEGRATION_BRIEF.md` as the controlling instruction for the first implementation pass.

## Approval boundary

Do not propagate this skin to the complete interface until the isolated Storybook Violetta card has been reviewed. The proof card determines the final frame thickness, texture strength, portrait crop, Energy pip scale, and selected-state intensity.
